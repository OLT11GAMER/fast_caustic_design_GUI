Fast Caustic Design now has a portable Windows x64 desktop app. Extract the entire ZIP, then open **FastCausticDesign.exe**.

- Drop a target image and optionally a source-light image, or load the included ring example.
- Preview the grayscale patterns and generate a lens with adjustable resolution, focal distance, thickness, and width.
- Follow generation, cancel a run, and inspect solver output from the app.
- Export the same result as Wavefront OBJ or binary STL.
